# 제주 안전관광 지식그래프 — 데이터 스키마 v3

작성: ㈜휴플 | 최종 갱신 2026-07-31

## 1. 이 릴리스의 변경점

v2 대비 **접근성 계층 전면 재구축**. 값 체계를 통제 어휘로 통일하고, 장애 유형 4축과
시설/활동 분리 판정을 도입했습니다. 안전(사고·위험) 계층은 v2를 그대로 승계합니다.

| 구분 | v2 | v3 |
|---|---|---|
| 접근성 값 | `가능/부분가능/어려움/Y/N/PARTIAL/확인필요` 혼재 (8종) | `FULL/PARTIAL/NONE/UNKNOWN` 4종 통일 |
| 장애 유형 | 이동(휠체어) 단일축 | 이동·시각·청각·발달 4축 |
| 판정 단위 | 장소 단위 단일 등급 | 시설접근 / 활동참여 분리 |
| 근거 | 출처 문자열만 | `evidenceType` + `verifyStatus` 코드화 |
| 행사 | 개최 여부만 | 개최 월·확정도 + 추천 게이트 |

**⚠ 하위 호환 없음**: `barrierFree` 필드는 폐지, `wheelchairAccess`의 `Y/N`은 `FULL/NONE`으로
치환되었습니다. `ac.wheelchairAccess='Y'` 형태의 기존 쿼리는 동작하지 않습니다.
`01_QUERY_TEMPLATES.cypher` [유형 4]에 갱신된 예시가 있습니다.

## 3. 통제 어휘

`CODE_DICTIONARY.csv` 참조. 요약:

- **접근성 등급** `FULL` 완전가능 / `PARTIAL` 부분가능 / `NONE` 불가 / `UNKNOWN` 미확인
- **가부** `AVAILABLE` / `CONDITIONAL` / `UNAVAILABLE` / `UNKNOWN`
- **placeKind** `SPOT` 관람 관광지 / `VENUE` 체험 장소 / `AREA` 구역 / `EVENT` 단기 행사
- **verifyStatus** `VERIFIED` / `PARTIAL` / `PENDING` / `EXCLUDED`
- **evidenceType** `FIELD_SURVEY` / `OFFICIAL_DOC` / `PUBLICATION` / `LEGAL_PRESUMPTION` /
  `CROSS_REFERENCE` / `INFERRED` / `NONE`

## 4. 판정 원칙 (해석 시 필수)

0. **축의 범위.** `mobilityAccess` 와 `wheelchairAccess` 는 관광지의 **도달·주출입·내부 이동**
   가능성을 뜻하며, 그 관광지에서 제공하는 **모든 체험·활동의 이용 가능성을 뜻하지 않습니다.**
   체험별 이용 가부는 `activityAccess` 를 별도로 적용합니다.
   예) 세리월드는 부지 진입로가 적정하나 카트·승마가 이용 불가여서 activityAccess=UNAVAILABLE 입니다.
       대유랜드는 부지 이동경로가 넓으나 개별 체험의 장애인 참여 가부는 별도 확인 대상입니다.

1. **시설접근 ≠ 활동참여.** 해변 편의시설은 접근 가능하나 입수는 불가한 경우가 있습니다.
   `facilityAccess`와 `activityAccess`를 함께 읽어야 합니다.
2. **AREA의 등급은 대표 접근지점 기준**입니다. 수 km 구역에 단일 등급을 부여한 것이므로
   구간 편차가 존재합니다. 올레 코스와 가파도 순환로 등 11곳에 `wheelchairSection` 실측 구간이 있습니다.
3. **UNKNOWN은 "불가"가 아니라 "미조사"**입니다. 추천에서 제외하되 불가로 안내하면 안 됩니다.
   `unknownAxisNote`에 확인처가 들어 있습니다.
4. **`recommendable='N'`은 추천 쿼리에서 반드시 제외**합니다. 개최 시기가 확인되지 않은
   행사가 여기 해당합니다.

## 7. 안전사고 데이터 — 위치 정밀도 2계층

소방 119 구급활동 기록은 **연도별로 위치 정보의 정밀도가 다릅니다.**
이를 숨기지 않고 `locationPrecision` 속성으로 명시합니다.

| 계층 | 연도 | 건수 | 위치 | 활용 |
|---|---|---|---|---|
| `POINT` | 2020-2021 | 3,933 | 위경도 | 1km 반경 집계 (`nearbyRiskScore`) |
| `EMD` | 2022-2023, 2025 | 7,770 | 읍면동 | 지역 집계 (`regionRiskScore`) |

- **2024년 5,060건 제외** — 원본에 위치 컬럼이 없어 읍면동조차 확인 불가.
  주소 재요청 중이며 확보 시 `03_INCREMENTAL_NEWS.cypher`와 동일한 방식으로 증분 적재합니다.
- **2020년 파일은 2011-2020 누적본**이므로 `DCLR_YR='2020'` 필터로 당해분만 사용했습니다.
- **질병(내과) 건 제외** — 심정지 등은 관광 안전사고가 아니므로 집계에서 뺐습니다.
  질병외 중 세부유형이 공란인 건(약 15%)도 위험패턴 매핑 불가로 제외됩니다.

### 위험도 — 직접 / 주변 2계층 분리 (중요)

사고 데이터는 **근거의 성격이 달라** 하나의 점수로 합치지 않습니다.

| | `directRiskScore` | `ambientRiskLevel` |
|---|---|---|
| 출처 | 뉴스 (장소 확정) | 소방 119 (지점 미상) |
| 의미 | **이 관광지에서 실제 사고 발생** | **인근에 사고가 잦음** |
| 보유 | 301곳 (29.3%) | 1,029곳 (100%) |
| 형식 | 0~1 연속값 (log 정규화) | `LOW`/`MEDIUM`/`HIGH` |
| 용도 | **소프트랭킹 Risk(p) 항** | **경고 문구 전용** |

**⚠ `ambientRiskLevel`을 점수로 환산해 랭킹에 넣지 마십시오.**
1km 반경 집계와 읍면동 집계는 면적이 달라(연평균 중앙값 6.5건 vs 11.7건, 최대 82건 vs 250건)
수치를 직접 비교할 수 없습니다. 합치면 넓은 읍면에 속한 한적한 관광지가 부당하게 감점됩니다.

> 실제 사례 — 천아계곡(P855)은 자체 사고 기록이 0건인데 소속 읍(애월읍, 연평균 250건)의
> 수치를 물려받아 이전 구조에서 **제주 전체 최고 위험(1.0)** 으로 산출되었습니다.
> 현재 구조에서는 `directRiskScore=0` (랭킹 감점 없음) + `ambientRiskLevel=HIGH` (경고 표시)로
> 분리되어, 추천은 정상적으로 되되 주의 안내가 함께 나갑니다.

`ambientRiskLevel`은 계열 간 비교를 피하기 위해 **각 계열 내부에서만 3분위**로 구간화했습니다.
`ambientBasis`로 어느 계열인지, `ambientNote`로 사용자에게 보여줄 문구를 확인하십시오.

- `NEARBY_1KM` 933곳 — "주변 1km 내 연평균 N건"
- `REGION` 96곳 — "○○읍 전체 연평균 N건 (정확한 발생 지점 미상)"

`directRiskScore`가 0인 728곳은 **"안전함"이 아니라 "확인된 사고 기록 없음"** 입니다.
뉴스 수집이 진행 중이므로 값이 늘어날 수 있습니다.

## 8. 사고 위치 3계층 (뉴스)

교통사고는 관광지가 아니라 도로에서 발생하므로, 사고의 위치를 3계층으로 보존합니다.
관광지에 연결되지 않는 사고도 **버리지 않고 좌표와 함께 유지**합니다.

| locationType | 건수 | 연결 | 설명 |
|---|---:|---|---|
| `PLACE` | 571 | `(:AccidentEvent)-[:OCCURRED_AT]->(:Place)` | 관광지 특정 |
| `ROAD` | 5 | `(:AccidentEvent)-[:OCCURRED_ON]->(:RoadSegment)` | 도로만 특정 |
| `ADDRESS` | 46 | 좌표만 | "서귀포시 남원읍 도로" 등 주소 기술 |
| `UNRESOLVED` | 28 | 좌표만 | KG 미등재 지명 |

650건 중 648건이 좌표를 보유하므로, 관광지에 연결되지 않아도 `point()` 기반
반경 질의에는 모두 참여합니다.

### RoadSegment (15종)

1100도로·5·16도로·평화로 등 주요 간선과 관광도로. 기사 본문의 도로명을 추출해
19건을 연결했습니다. 중산간 횡단·간선 도로에는 안개 위험이 `APPLIES_TO_ROAD` 로 연결됩니다.
※ 해안도로 26곳은 관광 목적지이므로 `Place`(placeKind=AREA)로 유지됩니다.
